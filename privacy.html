KineCount Privacy Policy

Last updated: June 1, 2026

This Privacy Policy explains how KineCount handles information when you use the app.

1. Overview

KineCount is an informational iPhone app that helps users count Squats, Push-ups, Sit-ups, and Plank valid hold time using the device camera.

KineCount is designed with a local-first, privacy-by-default approach. Core features work entirely without an account. Optional cloud sync and an optional leaderboard are available as explicit opt-in features and require Sign in with Apple.

2. Data Collected

Without optional features (default): KineCount does not collect personal data from users to external servers. All data stays on-device.

With optional cloud sync and/or leaderboard enabled (opt-in): the following data may be transmitted to the developer’s secure, Supabase-backed infrastructure:

  • Workout session data (exercise type, reps, duration, estimated calories, timestamps).
  • Profile data (age, sex, height, weight). Body fat percentage is optional, user-clearable, never public, and never included on the leaderboard.
  • Spend-ledger events (opaque charged/refunded minutes and timestamps — never contains app names, bundle IDs, or Screen Time usage data).
  • 5 Star Road progress and 30-Day Challenge state.
  • Public nickname and leaderboard score (weekly Push-ups, 5 Star Road) — leaderboard only.
  • Supabase Auth user identifier (internal only, never shown in the UI) — leaderboard and/or cloud sync only.

3. Data NOT Collected (in any configuration)

  • Camera frames, images, videos, or pose landmarks — processed on-device, discarded immediately, never stored or transmitted.
  • Email address or real name.
  • Phone number, postal address, or location data.
  • Device or advertising identifiers.
  • Apple Health data.
  • App names, bundle IDs, domains, or Screen Time / usage data.
  • FamilyActivitySelection token — stored locally on-device only, never transmitted.

4. Data Stored Locally on the Device

KineCount may store the following information locally on your iPhone:

  • Workout sessions, repetition counts, Plank valid hold time, estimated calories.
  • Local workout history, goals, streaks, and all-time totals.
  • Earned minutes and local spendable minute balance.
  • App preferences.
  • App Limits selection (opaque token — app names and bundle IDs are never accessible to KineCount).

Local data stays on the user’s device. If optional cloud sync is not enabled, it is never sent to the developer.

5. Camera and On-Device Processing

KineCount uses the iPhone camera to count supported exercises.

Camera processing runs entirely on-device. KineCount does not upload images, videos, camera frames, or pose landmarks to external servers.

Camera permission is used only to enable camera-based workout sessions.

6. App Limits and Screen Time Access

KineCount may request Screen Time access to let the user select apps and use the optional App Limits feature.

This feature allows the user to choose specific apps, earn minutes by completing workout sessions, and spend those minutes to temporarily unlock the selected apps.

KineCount does not read app usage data. KineCount does not know which apps the user actually opened, when, or for how long.

KineCount does not use the App and Website Usage entitlement, DeviceActivityEvent, ShieldActionExtension, or ShieldConfigurationExtension.

The app selection is handled and stored locally on the device. KineCount does not expose app names, bundle IDs, domains, category names, or raw selection data in user interface, logs, errors, or documentation. The app selection token is never transmitted to the developer.

7. Optional Cloud Sync

When the user enables cloud sync via Sign in with Apple, workout data syncs to the user’s own account in the developer’s Supabase-backed infrastructure. Data is protected by row-level security — each user can only access their own data.

What IS synced: workout history, profile, spend-ledger events (opaque minutes only), 5 Star Road progress, and 30-Day Challenge state.

What is NEVER synced: camera frames, pose landmarks, FamilyActivitySelection token, Screen Time data, app names or bundle IDs, Apple Health data.

8. Optional Leaderboard

The leaderboard is entirely opt-in. It uses Sign in with Apple with zero scopes — no email address or real name is requested or accessed.

The user chooses a public nickname. Only the public nickname and aggregate score (weekly Push-ups, 5 Star Road) are visible to other users.

No body metrics, no camera data, no Screen Time data, and no device identifiers are ever on the leaderboard.

9. Account Creation and Deletion

Accounts are created when the user signs in with Apple to enable cloud sync and/or the leaderboard.

In-app account deletion is available at Profile → Account → Delete account. Deletion is immediate and cascading — all server-side data linked to the account is deleted, including archived workout sessions, with no exceptions. Best-effort Apple token revocation is performed. Local data is cleared immediately.

Users can also revoke Sign in with Apple access at any time in iOS Settings → Apple ID → Password & Security → Apps Using Apple ID.

10. Data Sharing

KineCount does not sell personal data.

KineCount does not share personal data with advertisers, ad networks, analytics providers, data brokers, or third parties for tracking purposes.

Data synced to the developer’s infrastructure is the user’s own data, protected by row-level security and used solely to provide the cloud sync and leaderboard features.

11. Data Retention

Local data: stays on the device until the app is deleted or the user clears it.

Cloud data — workout sessions: subject to a 24-month archive policy (moved to an archive table after 24 months; not hard-deleted until account deletion).

All other cloud tables: no automatic retention limit currently. Data is retained until account deletion.

Account deletion: immediately and permanently removes all server-side data linked to the account, including the archive table, with no exceptions.

12. Revoking Permissions

Users can revoke KineCount permissions at any time in iOS Settings, including:

  • Camera access.
  • Screen Time access, where applicable.

Revoking permissions may limit or prevent features that depend on those permissions from working.

13. Children

KineCount is not specifically directed to children and does not knowingly collect personal data from children.

14. Health, Exercise, and Limitations

KineCount is informational only.

Counts, valid hold time, and estimated calories are camera-based estimates and may be imperfect. Lighting, framing, body position, clothing, and iPhone placement may affect results.

KineCount does not provide medical advice, injury prevention, diagnosis, physiotherapy, rehabilitation, form correction, coaching, scoring, clinical analysis, biomechanical analysis, or treatment guidance.

15. Changes to This Policy

This Privacy Policy may be updated from time to time. The latest version will be made available on this page.

16. Contact

Política de Privacidade do KineCount

Última atualização: 1º de junho de 2026

Esta Política de Privacidade explica como o KineCount trata informações quando você usa o aplicativo.

1. Visão geral

KineCount é um aplicativo informacional para iPhone que ajuda o usuário a contar agachamentos, flexões, abdominais e tempo válido de prancha usando a câmera do aparelho.

KineCount foi desenvolvido com uma abordagem local-first e de privacidade por padrão. Os recursos principais funcionam completamente sem conta. Sincronização em nuvem e placar online são recursos opcionais de adesão explícita que exigem Login com Apple.

2. Dados coletados

Sem recursos opcionais (padrão): KineCount não coleta dados pessoais do usuário para servidores externos. Todos os dados ficam no aparelho.

Com sincronização em nuvem e/ou placar habilitados (adesão voluntária): os dados a seguir podem ser transmitidos para a infraestrutura segura do desenvolvedor:

  • Dados de sessão de treino (tipo de exercício, repetições, duração, calorias estimadas, timestamps).
  • Dados de perfil (idade, sexo, altura, peso). Percentual de gordura corporal é opcional, pode ser apagado pelo usuário, nunca é público e nunca aparece no placar.
  • Eventos de ledger de minutos (minutos cobrados/reembolsados de forma opaca e timestamps — nunca contém nomes de apps, bundle IDs ou dados de Tempo de Uso).
  • Progresso no 5 Star Road e estado do Desafio 30 Dias.
  • Apelido público e pontuação no placar (push-ups semanais, 5 Star Road) — somente para o placar.
  • Identificador de usuário do Supabase Auth (uso interno, nunca exibido na interface) — somente para placar e/ou sincronização em nuvem.

3. Dados que NÃO são coletados (em nenhuma configuração)

  • Frames de câmera, imagens, vídeos ou marcos de pose — processados no aparelho, descartados imediatamente, nunca armazenados ou transmitidos.
  • Endereço de e-mail ou nome real.
  • Número de telefone, endereço postal ou localização.
  • Identificadores de dispositivo ou publicidade.
  • Dados do Apple Health.
  • Nomes de apps, bundle IDs, domínios ou dados de Tempo de Uso.
  • Token FamilyActivitySelection — armazenado apenas localmente no aparelho, nunca transmitido.

4. Dados armazenados localmente no aparelho

KineCount pode armazenar localmente no seu iPhone as seguintes informações:

  • Sessões de treino, contagens de repetições, tempo válido de prancha, calorias estimadas.
  • Histórico local de treinos, metas, sequências e totais acumulados.
  • Minutos ganhos e saldo local de minutos disponíveis.
  • Preferências do aplicativo.
  • Seleção de apps para Limites de apps (token opaco — nomes e bundle IDs de apps nunca são acessíveis ao KineCount).

Os dados locais ficam no aparelho do usuário. Se a sincronização em nuvem não estiver habilitada, esses dados nunca são enviados ao desenvolvedor.

5. Câmera e processamento no aparelho

KineCount usa a câmera do iPhone para contar exercícios compatíveis.

O processamento da câmera ocorre inteiramente no próprio aparelho. KineCount não envia imagens, vídeos, frames de câmera ou marcos de pose para servidores externos.

A permissão de câmera é usada apenas para permitir o funcionamento das sessões de treino baseadas em câmera.

6. Limites de apps e acesso ao Tempo de Uso

KineCount pode solicitar acesso ao Tempo de Uso para permitir que o usuário selecione apps e use o recurso opcional Limites de apps.

Esse recurso permite que o usuário escolha apps específicos, ganhe minutos ao completar sessões de treino e use esses minutos para liberar temporariamente os apps selecionados.

KineCount não lê dados de uso de apps. KineCount não sabe quais apps o usuário realmente abriu, quando abriu ou por quanto tempo usou.

KineCount não usa o entitlement App and Website Usage, não usa DeviceActivityEvent, não usa ShieldActionExtension e não usa ShieldConfigurationExtension.

A seleção de apps é tratada e armazenada localmente no aparelho. KineCount não expõe nomes de apps, bundle IDs, domínios, nomes de categorias ou dados brutos de seleção em interface, logs, erros ou documentação. O token de seleção nunca é transmitido ao desenvolvedor.

7. Sincronização em nuvem opcional

Quando o usuário habilita a sincronização em nuvem via Login com Apple, os dados de treino são sincronizados com a conta própria do usuário na infraestrutura do desenvolvedor. Os dados são protegidos por segurança em nível de linha — cada usuário só pode acessar os próprios dados.

O que É sincronizado: histórico de treinos, perfil, eventos de ledger de minutos (somente minutos opacos), progresso no 5 Star Road e estado do Desafio 30 Dias.

O que NUNCA é sincronizado: frames de câmera, marcos de pose, token FamilyActivitySelection, dados de Tempo de Uso, nomes ou bundle IDs de apps, dados do Apple Health.

8. Placar online opcional

O placar é inteiramente opcional e de adesão voluntária. Usa Login com Apple com zero escopos — nenhum endereço de e-mail ou nome real é solicitado ou acessado.

O usuário escolhe um apelido público. Apenas o apelido público e a pontuação agregada (push-ups semanais, 5 Star Road) são visíveis para outros usuários.

Nenhuma métrica corporal, dado de câmera, dado de Tempo de Uso ou identificador de dispositivo aparece no placar.

9. Criação e exclusão de conta

As contas são criadas quando o usuário realiza o Login com Apple para habilitar sincronização em nuvem e/ou o placar.

A exclusão de conta no aplicativo está disponível em Perfil → Conta → Excluir conta. A exclusão é imediata e em cascata — todos os dados vinculados à conta no servidor são excluídos, incluindo sessões arquivadas, sem exceções. É feita a revogação do token Apple na medida do possível. Os dados locais são apagados imediatamente.

O usuário também pode revogar o acesso ao Login com Apple a qualquer momento em Ajustes do iOS → Apple ID → Senha e Segurança → Apps que usam o Apple ID.

10. Compartilhamento de dados

KineCount não vende dados pessoais.

KineCount não compartilha dados pessoais com anunciantes, redes de anúncios, provedores de analytics, data brokers ou terceiros para rastreamento.

Os dados sincronizados com a infraestrutura do desenvolvedor são os próprios dados do usuário, protegidos por segurança em nível de linha e utilizados exclusivamente para fornecer os recursos de sincronização em nuvem e placar.

11. Retenção de dados

Dados locais: permanecem no aparelho até que o aplicativo seja excluído ou os dados sejam apagados pelo usuário.

Dados em nuvem — sessões de treino: sujeitos a uma política de arquivo de 24 meses (movidos para uma tabela de arquivo após 24 meses; não excluídos permanentemente até a exclusão da conta).

Demais tabelas em nuvem: sem limite automático de retenção atualmente. Os dados são mantidos até a exclusão da conta.

Exclusão de conta: remove imediata e permanentemente todos os dados vinculados à conta no servidor, incluindo a tabela de arquivo, sem exceções.

12. Revogação de permissões

O usuário pode revogar permissões do KineCount a qualquer momento nas configurações do iOS, incluindo:

  • Acesso à câmera.
  • Acesso ao Tempo de Uso, quando aplicável.

A revogação de permissões pode limitar ou impedir o funcionamento de recursos que dependem dessas permissões.

13. Crianças

KineCount não é direcionado especificamente a crianças e não coleta conscientemente dados pessoais de crianças.

14. Saúde, exercício e limitações

KineCount é apenas informativo.

Contagens, tempo válido e calorias estimadas são estimativas baseadas na câmera e podem ser imperfeitas. Iluminação, enquadramento, posição do corpo, roupa e posicionamento do iPhone podem afetar os resultados.

KineCount não oferece aconselhamento médico, prevenção de lesão, diagnóstico, fisioterapia, reabilitação, correção de forma, coaching, pontuação, análise clínica, análise biomecânica ou orientação de tratamento.

15. Alterações nesta política

Esta Política de Privacidade pode ser atualizada ocasionalmente. A versão mais recente ficará disponível nesta página.
